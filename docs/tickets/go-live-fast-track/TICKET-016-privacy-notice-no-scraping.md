# Ticket 016: Finalize Privacy Notice for No-Scraping Scope

## Context
Go-live scope is reduced to user-provided job context (URL/text), without platform scraping in production.

## Goal
Publish a production-ready privacy notice that reflects the actual no-scraping data flow.

## Scope
- Privacy notice content updates.
- Frontend visibility and linking.
- Version/date tracking.

## Tasks
- Document collected data categories for the reduced scope.
- Document legal basis, purpose, retention, and data recipients.
- Include user rights handling path (access, deletion, correction, export contact).
- Link the privacy notice from relevant frontend entry points.
- Add version/date and owner for future updates.

## Definition of Done
- Privacy notice reflects current production behavior (no scraping path).
- Notice is visible in frontend and accessible without login.
- Legal/privacy owner reviewed and approved the text.

## Acceptance Criteria
- A user can find the privacy notice in one click from the main workflow.
- Notice explicitly states that job context is user-provided in this go-live scope.

## Priority
P0
